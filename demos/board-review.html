看板 UI 美化 · 三方案对比

每个方案都用 S04 分镜的真实数据做了单行高保真 mockup（深色区域即产品实际效果，可横向滚动）。三案共享同一套硬约束：八分区结构不变、@实体保留 chip 语义、深色主题、画布缩小后仍可辨。

现状诊断
  • 「画面描述 / 色彩基调 / 光影氛围」等小标题每行重复出现，是最大的视觉噪音源
  • 层级全靠字号硬撑，分区标题、字段标题、正文三级界限模糊
  • 绿色实体 chip 与青绿按钮散落各处，黑底上过跳，缺乏收敛的语义色系统
  • 右侧只读占位列与可编辑区视觉权重相同；行状态（已改未重生成）无引导
A

Slate · 灰阶分层精修

结构零改动，纯视觉治理 —— 落地成本最低
  • 三级层级重建：分区标题改 9.5px 加宽字距灰标，字段标题降为极小灰注，正文亮度提高
  • 语义色收敛：chip 统一深灰底，仅左缘 2px 色相条区分角色 / 场景 / 道具（低饱和青 / 琥珀 / 紫）
  • 只读列弱化：55% 透明度 + 虚线分隔，不再与创作区抢权重
  • 状态引导：行左缘白条 = 选中；镜号旁琥珀点 = 已修改待重新生成；按钮全部幽灵化

B

Timeline · 轨道视图

列头上提一次出现，行内彻底去重 —— 信息密度收益最大
  • 列头上提：八分区标题合并为表头一次出现（sticky），行内不再逐行重复
  • 轨道头：镜号列压缩成剪辑软件式 track head —— 镜号 + 时长 + 状态灯（绿已生成 / 琥珀已修改 / 灰待生成）
  • 行内前缀：字段小标题改为「画面 ·」「色彩 ·」灰色前缀融进正文首行，纵向空间省约 30%
  • 剧情段色带：P01 / P02 做贯穿横条，青灰色相条 + 段描述，行挂段下
  • chip 极简化：@实体去底色，色相文字 + 点状下划线，正文密度下噪音最低

C

Dossier · 档案卡

每镜一张横向档案卡，留白最充分 —— 阅读体验最好
  • 卡片化：行变独立圆角卡，卡间 14px 空隙，剧情段作为卡组标题存在
  • 三栏重组：元信息栏（镜号大字 + 状态）/ 创作主栏（画面 + 表演 + 空间两列排布）/ 声音 + 占位窄栏
  • 标签芯片化：字段小标题变 9px 深灰 label-chip 行内前缀，正文同行起排
  • 操作悬浮化：✎ 编辑入口收进卡右上 hover 工具条，静止时零按钮噪音
  • 占位折叠：只读提示词折叠为单行摘要，hover / 点击展开全文

推荐

A + B 混合：以 A 的灰阶分层与语义色系统为视觉基底（低风险打底），叠加 B 的「列头上提 + 行内前缀」—— 它直击最大噪音源（逐行重复的小标题），两者合计 2–3 天可落地，且都不动八分区数据结构。

C 的「占位折叠」「hover 工具条」可作为二期增量单独引入，不必绑定整个卡片化改版。
